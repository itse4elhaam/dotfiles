# Desktop dictation

On Pop!_OS/X11, place the caret in an editable field, hold **Super + Left Alt**, speak, and release either key. Both press orders work. A blue waveform follows the microphone on the active window’s monitor. The preview above the waveform updates as you speak. Press **Esc while holding the shortcut** to discard the recording.

Run `apps/desktop-dictation/install.sh` from this checkout to install or update the user service. It uses the system Python 3.10 with GTK 3, PyGObject, pycairo and python-xlib, PulseAudio-compatible `parec`, and the Linux x64 T3 Code Nightly AppImage in `~/Applications`. Download **Parakeet Unified English 0.6B** and the Silero silence filter through T3 once. T3 can be closed during dictation.

The worker reads T3’s installed Q8_0 GGUF and Silero v6.2, streams locally, and applies the filler-word, silence-filter and preferred spelling/alias settings from `~/.t3/userdata/client-settings.json`. The model supplies punctuation. Cleanup also recognizes explicit numeric repairs such as “set it to 42, sorry, 24”. No cloud text-generation pass runs. Audio stays in process memory. After a successful recording the model stays warm for 15 idle minutes. If recognition fails mid-utterance, the last available partial can be copied from the overlay. Auto-paste briefly serves the transcript, then restores the previous clipboard formats. Clipboard managers can retain paste history. An unsupported clipboard format or an oversized selection stays untouched and the overlay offers Copy.

Clicking or typing during finalization, switching windows, or changing fields with the mouse leaves the transcript in the overlay. Choose **Copy** to copy the displayed transcript or **×** to dismiss it. Unhandled transcripts stay available, newest first, until you copy them, dismiss them, or lock the session.

A second hold can record while the first field is reading its paste. If the application takes over 1.8 seconds to read, automatic pasting pauses for that application. Both transcripts remain available through **Copy**. The pause also applies to later holds in that application. Choose **Resume** once the application is responding to allow automatic paste on future holds. While dictation owns the restored clipboard, one late text read from that application returns empty. Other applications continue to see the previous clipboard during automatic delivery.

If you choose **Copy** while a shortcut might still be waiting, other X11 clients can paste the copied text immediately. Dictation answers the first text read from each affected client with empty text. X11 identifies the requesting client but cannot tell which field or shortcut caused the read. If your deliberate paste is the first read and inserts nothing, paste again. An external clipboard owner serves its own data. Copying another recovery card brings the guard back for any still-outstanding client.

Applications can move their own caret or switch internal fields without notifying X11. Keep the caret in place until the overlay finishes. Auto-paste uses Ctrl+V in GUI applications and Ctrl+Shift+V in common terminal emulators. The recording limit is five minutes.

In xterm and urxvt, choose **Copy** in the overlay, then paste with your terminal’s CLIPBOARD binding. In xterm, Shift+Insert reads the selection configured by `selectToClipboard`, which defaults to PRIMARY. In urxvt, Ctrl+Meta+V reads CLIPBOARD, but each terminal instance can choose which modifier acts as Meta. Dictation sends no paste keys to these terminals. [xterm manual](https://invisible-island.net/xterm/manpage/xterm.html#VT100-Widget-Resources:selectToClipboard) · [urxvt manual](https://manpages.debian.org/bookworm/rxvt-unicode/urxvt.1.en.html#THE_SELECTION)

Set `T3_DICTATION_APPIMAGE=/absolute/path/to/T3.AppImage` in `~/.config/desktop-dictation.env` if T3 moves. Restart with `systemctl --user restart desktop-dictation`. For diagnostics use `journalctl --user -u desktop-dictation`. Disable with `systemctl --user disable --now desktop-dictation`.

Run `/usr/bin/python3 apps/desktop-dictation/test_x11.py` with Xvfb and xdotool on PATH. Add `--real-model` for recorded English audio through the bundled worker. The test starts its own X server and supplies microphone fixtures.
